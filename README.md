# Изотоп РК — локальный дизайн-прототип

Откройте [index.html](./index.html) двойным кликом в браузере. Прототип работает без сервера; переходы между страницами сделаны через фрагмент адреса.

## Страницы

Главная, Все услуги, Проектирование, Индивидуальный дозиметрический контроль, Радиационный контроль, Метрология, Доставка оборудования, О компании, Контакты.

## Что важно при показе

- Это визуальная концепция, а не действующий сайт и не реализация на WordPress.
- Формы демонстрационные и не отправляют данные.
- Два изображения созданы для макета; перед публикацией потребуется утвердить или заменить их.
- Темы статей, карточки документов и схематические карты — временные элементы. Реальные документы, точный состав услуг, формулировки и условия доставки должны быть подтверждены компанией.
- Номера лицензий, аккредитаций, цены, сроки, статистика, клиенты и отзывы не выдуманы.
